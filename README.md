## Ограничения

- Копия на дату снятия. Банк обновляет стратегию раз в квартал; новая версия появится по новому адресу.
- Графики в копии статичны; ссылка на интерактивную версию указана под каждым.
- 5 графиков в краткой версии опубликованы банком как картинки, их значения расшифрованы вручную и помечены.
- Удалены меню, подвал, декоративные иллюстрации и фото авторов. Юридические оговорки банка сохранены в конце документов.
- Материал банка, не индивидуальная инвестиционная рекомендация.
